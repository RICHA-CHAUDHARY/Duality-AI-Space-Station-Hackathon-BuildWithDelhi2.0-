## 🛰 About the Hackathon

This repository is our official submission for the *Duality AI - Space Station Hackathon* under the *BuildWithIndia 2.0 / BuildWithDelhi2.0* track. Organized by *Duality AI, the challenge focuses on training object detection models using **synthetic data generated by Falcon*, a digital twin simulation platform.

Participants are tasked with building and optimizing AI models capable of detecting mission-critical objects in a simulated space station environment — helping improve astronaut safety and operational reliability.

---

## 🎯 Objective

- Train an object detection model (YOLOv8) to accurately identify:
  - 🔧 Toolbox
  - 🧯 Fire Extinguisher
  - 🪫 Oxygen Tank
- Overcome challenges like:
  - Varying lighting conditions
  - Occlusions and overlapping objects
  - Multiple viewing angles and distances
- Bonus: Develop a usable app powered by the trained model for real-time inference.

---

## 🧠 Model Architecture & Training

- *Model Used:* YOLOv8 (You Only Look Once v8)
- *Framework:* Ultralytics YOLOv8
- *Training Data:* Falcon simulation dataset (Train/Val/Test)
- *Training Environment:* Conda-based virtual environment (EDU)

---

## 📊 Final Evaluation Metrics (YOLOv8 Validation)

*Overall Model Performance:*
- 📈 *mAP@0.5:* 0.918
- 🎯 *mAP@0.5:0.95:* 0.779  
- ✅ *Precision (avg.):* 0.965 
- 🔄 *Recall (avg.):* 0.846  

*📌 Class-wise Detection Performance (mAP@0.5):*

|--------------------|---------|
| 🧯 Fire Extinguisher | 0.937  |
| 🔧 Toolbox           | 0.918  |

## 🔁 Model Update Strategy with Falcon

To keep the model up to date:
- *Continual Learning:* Use Falcon to regenerate synthetic data with new object conditions or layouts.
- *Domain Adaptation:* Fine-tune the model on updated data distributions.
- *Feedback Loop:* Use prediction errors to request new simulation scenes from Falcon for re-training.

## 🧪 How to Run

1. Clone the repo:
   ```bash
   git clone https://github.com/RICHA-CHAUDHARY/Duality-AI-Space-Station-Hackathon-BuildWithDelhi2.0-.git
   cd Duality-AI-Space-Station-Hackathon-BuildWithDelhi2.0-

2. Setup environment:

conda create -n EDU python=3.9
conda activate EDU
pip install -r requirements.txt


3. Train the model:

python train.py


4. Run predictions:

python predict.py


5. Launch app:

python app.py
